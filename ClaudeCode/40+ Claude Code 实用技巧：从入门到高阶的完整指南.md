Crypto第一深情

2026-3-418:00陕西


经过十一个月的深度使用和社区贡献，围绕 Claude Code 已经涌现出大量实用技巧，足以大幅提升你的开发效率。

无论你是刚入门的新手，还是希望更上一层楼的老用户，这份包含四十余条技巧的指南，覆盖了从基础必备到高阶进阶的方方面面。

第一章：基础必备——每次会话都应该知道的事
从这里开始。这些基本功会立刻提升你的每一次 Claude Code 会话体验。


1. 自定义状态栏
设置自定义状态栏，显示当前模型、目录、Git 分支、未提交文件数、同步状态和 Token 用量。这让你一眼就能掌握工作上下文，无需反复询问 Claude。

2. 掌握核心命令
熟练使用以下命令：/usage 检查 Token 消耗、/mcp 管理 Model Context Protocol 服务器、/stats 查看会话统计数据、/clear 在需要全新开始时清空上下文。

3. 语音输入加速
使用语音转录工具（SuperWhisper、MacWhisper 或类似工具）更快地与 Claude 沟通。许多开发者发现，口述复杂需求比打字快得多。

4. 任务分解
将复杂任务拆解为更小的、可管理的子问题。Claude 处理聚焦的请求比宽泛的要求效果更好。通过清晰的步骤迭代推进，你会获得更精确的结果。

5. 让 Claude 处理 Git 操作
把提交（commit）、创建分支（branch）和拉取请求（PR）交给 Claude。使用 gh CLI 进行高级查询。只需说一句「为这个创建一个 PR」，Claude 就会处理整个流程。

6. 及时开启新会话
切换到新话题时，开启新的对话以保持最佳性能。长对话会导致质量下降，因此在切换上下文时，务必重新开始。

7. 灵活导出结果
使用 /copy 复制响应内容，用剪贴板命令如 pbcopy，将结果直接写入文件，在 VS Code 中打开，或在浏览器中打开 URL。

8. 创建快捷别名
为常用操作创建快捷方式：c 代表 Claude，ch 代表 Chrome，gb 代表 GitHub Desktop，co 代表 VS Code。这些小优化日积月累能省下大量按键。

9. 使用 Compact 和 Handoff
使用 /compact 或 /handoff 在开启新对话前创建摘要文档。这在给 Claude 一个全新上下文的同时，保留了重要的信息。

10. 快速迭代循环
写代码、运行、验证输出、再重复。使用 tmux 进行交互式终端测试。这种快速迭代循环正是 Claude Code 最擅长的场景。


第二章：进阶技巧——从日常用户到进阶用户的跨越
这些技巧将让你的工作流程升级，拉开与普通用户的差距。

11. 粘贴网页内容
对于 Claude 无法直接访问的页面，全选页面内容并粘贴到 Claude Code 中。这可以绕过许多访问限制。

12. 用 Gemini CLI 获取受限内容
创建一个 Skill，使用 Gemini CLI 从 Claude 无法访问的网站获取内容，比如某些 Reddit 帖子或被屏蔽的网站。

13. 深度定制你的工具
自定义状态栏、转录工具配置，或简化系统提示词。在这些定制上投入的时间，每天都会产生回报。

14. 搜索历史会话
在 ~/.claude/projects/ 中查找过去的对话，或直接让 Claude 帮你搜索。你的会话历史是一个宝贵的知识库。

15. 级联式多终端工作法
使用终端标签页（Tab）的级联方法，同时专注于三到四个任务。每个标签页运行各自独立的 Claude 会话。


16. 精简系统提示词
高级用户可以通过修补 Claude CLI 包，将系统提示词从约 19K token 精简到 9K token——节省 50% 的空间，为你的实际工作释放更多上下文容量。

17. Git Worktree 并行开发
使用 Git Worktree 在不同目录中同时处理多个分支。这实现了真正的并行开发，无需来回切换分支。


18. 递增式轮询长任务
对于 CI 构建或 Docker 操作等耗时任务，让 Claude 以递增间隔（1分钟、2分钟、4分钟、8分钟）检查状态，而不是持续轮询。

19. 语音口述 + Claude 编辑
用语音口述草稿，然后与 Claude 逐行审阅。这将 Claude 变成了一个强大的编辑搭档。

20. Markdown 优先工作流
用 Markdown 写文档，与 Claude 对话，保存为 Markdown，然后转换到其他平台。Markdown 是现代文档的通用语言。

21. 通过 Notion 保留链接格式
从 Slack 或其他会剥离格式的应用复制内容时，先粘贴到 Notion 中以保留链接。

22. 容器化运行
在容器中运行 Claude Code，搭配
--dangerously-skip-permissions 参数用于无人值守任务。这将潜在的危险操作隔离在安全环境中。

23. 会话分支管理
使用 /clone 来分支对话，或使用 /half-clone 在保留近期工作的同时减少上下文。这些是强大的会话管理工具。

24. 使用 realpath 提供绝对路径
使用 realpath 命令为不同目录中的文件提供完整的绝对路径。这在复杂项目结构中避免了路径歧义。

25. 理解四种配置机制
CLAUDE.md 始终加载，Skill 按需加载，斜杠命令（Slash commands）手动触发，插件（Plugins）是打包的工具集。针对不同场景使用合适的机制。

第三章：高阶心法——顶尖用户的秘密武器
这些是让你真正脱颖而出的技术。掌握它们的人，属于金字塔顶端的那 1%。


26. 交互式 PR Review
用 Claude 作为交互式 PR 审查员：逐文件推进，掌控节奏和细节深度。这将代码审查从一次性批处理变成了一场引人入胜的对话。

27. Claude 驱动的研究能力
用 Claude 做研究：调试 GitHub Actions、分析 Reddit 讨论、探索代码库。Claude 在综合分析和深入调查方面能力出众。

28. 多维度验证机制
使用测试用例、可视化 Git 客户端、草稿 PR，并让 Claude 复查自己的工作。验证与生成同等重要。

29. 调试 GitHub Actions
使用 /gha 斜杠命令调查 GitHub Actions 失败，找到根因并给出修复建议。Claude 在基础设施调试方面的能力超乎想象。

30. CLAUDE.md 极简主义
从空白的 CLAUDE.md 开始，只添加需要重复说明的指令，并定期审查其相关性。少即是多。

31. 按任务重要性选择工作模式
在「氛围编程」（vibe coding）和深度钻研之间做平衡：根据任务的关键程度来选择。不是每个功能都需要一丝不苟的关注。


32. 安全扫描
使用 cc-safe CLI 扫描潜在危险的已批准命令，比如 rm -rf 或 sudo。即使有 AI 助手，安全意识依然重要。

33. 测试驱动开发（TDD）
使用测试驱动开发：先写失败的测试，再写代码让测试通过。Claude 在 TDD 工作流中表现出色。

34. 探索未知领域
用 Claude 在不熟悉的领域中迭代探索和解决问题。Claude 可以引导你穿越你尚未涉足的技术领域。

35. 后台进程和并行子代理
使用 Ctrl+B 将进程放到后台，运行子代理（subagent）进行并行工作。Claude Code 支持多任务处理。

36. 为自己打造工具
构建自定义的小工具：小型项目、脚本和实用程序，在 Claude 的帮助下人人都可以做到。

37. 终端快捷键
掌握终端快捷键：Ctrl+A/E 跳到行首/行尾，Option+Left/Right 按单词导航，Ctrl+W/U/K 删除单词/整行，Ctrl+G 打开外部编辑器。

38. 先规划后原型
在项目早期花时间规划高层决策，但快速原型有助于验证技术选型。两种方法各有用武之地。

39. 持续重构
审查代码并让 Claude 简化过度复杂或包含不必要改动的部分。重构是一个持续的过程。

40. 将重复操作归零
把常用命令放入 Skill、脚本或 CLAUDE.md 中。目标是将重复工作降到零。

第四章：生态与资源——保持与时俱进
41. 善用内置插件
官方打包的插件提供了
/dx:gha、/dx:handoff、/dx:clone、/dx:half-clone、/dx:reddit-fetch、/dx:review-claudemd
等日常必备工具。

42. 持续关注更新
主动了解 Claude 的最新动态：直接问 Claude 自身的能力、查看 /release-notes、关注 r/ClaudeAI 以及官方社交账号。Claude Code 迭代速度极快，保持信息同步至关重要。

43. 一键快速配置
如果想快速部署多条技巧，可以运行以下设置脚本：

bash <(curl -s ykdojo/claude-code-tips/main/scripts/setup.sh)
这个脚本会同时配置多项优化，帮你以最快速度达到最佳生产力状态。


总结
Claude Code 的强大之处不仅在于它能写代码，更在于它可以成为你整个开发工作流的核心引擎。从基础的会话管理到高阶的并行开发，从简单的 Git 操作到复杂的 CI/CD 调试，这 40+ 条技巧覆盖了日常开发中几乎所有场景。

关键在于：不要试图一次性掌握所有技巧。从基础开始，逐步将进阶和高阶技巧融入你的日常工作流。随着时间推移，这些技巧会叠加出惊人的效率提升。

记住，最好的工具是你真正会用的工具。选择对你当前工作最有价值的几条技巧，先把它们变成肌肉记忆，然后再逐步扩展。
