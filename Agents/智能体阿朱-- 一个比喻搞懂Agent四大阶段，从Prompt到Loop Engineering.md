· 第一个阶段：prompt提示词阶段。把agent比作刚入职的实习生，啥都不懂，根本不敢让他干正事，只能给最明确的指令去帮我打份饭，去把这份稿打印好，这就是提示词工程。英文prompt engineering，得不停给他明确指令，指令越清楚干得越靠谱，这就是入门阶段。慢慢他熟门熟路，这时候就得让他干正事了。
比如让他找李总报销，但得告诉他李总下午两点才处理报销。有同学问了这阶段要做啥？得把公司的背景知识、规章流程也就是所谓的上下文都告诉他，这就是上下文工程。英文context engineering，等他成了正式资深员工，敢直接放手让他干吗？肯定不敢，得给他搭好约束机制。
就像派老员工带新人一样，就像公司有hr帮他管团队，有财务卡他的预算，这些都是约束机制，这就是驾驭工程。英文harness engineering，再后来a政的能力升级成部门经理了，这些微观约束就没用了，不用管他怎么干，只需要告诉他要啥结果就行。只看结果不盯过程，这就是loop循环工程的核心。
只给明确目标，至于怎么做用啥手段完全不用操心。用了loop的agent平台，它会自动做规划试各种方法，甚至还能生成一堆子agent帮它干活。用实习生到部门经理这个比喻，是不是就把prompt context harness loop四大工程串明白了？
